[Zed](https://zed.dev/) 是一个代码编辑器，开箱即用地支持许多语言。通过安装扩展可以支持更多语言。

## Python

Zed 开箱即用地支持 Pixi 和 Python。
如果 Zed 还没有这样做，请在环境选择器中选择合适的 Pixi 环境，就可以使用了！

![Zed Python Environment Selector](../../assets/zed-python-env-selector.png)

## Direnv

Zed 开箱即用地支持 Direnv。
按照我们在 [Direnv 页面](../third_party/direnv.md) 中描述的使用 Pixi 设置 Direnv，Zed 将自动激活环境。
